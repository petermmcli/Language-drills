Section 1: Chinese → English

1. 跟 🔊

► Pinyin
gēn
► Answer
B. with / and — 跟 (gēn) = with, and, or follow. It overlaps with 和 (hé) as a conjunction meaning "and," but 跟 more strongly implies doing something together with someone.

2. 一点 🔊

► Pinyin
yīdiǎn
► Answer
A. a little — 一点 (yīdiǎn) = a little / a bit. Compare 有点儿 (yǒudiǎnr) = somewhat, used before adjectives; 一点 often comes after verbs or at the end of a sentence.

3. 再吃 🔊

► Pinyin
zài chī
► Answer
B. eat again / eat more — 再吃 (zài chī): 再 = again / more, 吃 = eat. Used in patterns like 别再吃了 (don't eat anymore) or 我想再吃一碗 (I want another bowl).

4. 吃多 🔊

► Pinyin
chī duō
► Answer
D. eat too much — 吃多 (chī duō): verb + resultative complement. 多 here acts as a result: "ate to the extent of having too much." E.g., 我吃多了 (I've eaten too much).

5. 别再吃了 🔊

► Pinyin
bié zài chī le
► Answer
C. don't eat anymore — 别再吃了 (bié zài chī le): 别 = don't (command), 再 = anymore, 了 = completion/change marker. This is a polite command. Compare: 不想再吃了 (don't want to) vs. 不能再吃了 (can't).
Section 2: English → Chinese

Read the English. Choose the correct Hanzi. Use 🔊 on each option to hear it. Toggle ► Pinyin to reveal readings.

1. I'm full

► Pinyin
A. 我累了 — Wǒ lèi le
B. 我渴了 — Wǒ kě le
C. 我饱了 — Wǒ bǎo le
D. 我忙了 — Wǒ máng le
► Answer
C. 我饱了 (Wǒ bǎo le) — 饱 (bǎo, 3rd tone) = full (from eating). The 了 marks a change of state. Common phrases: 你吃饱了吗？ (Are you full?) / 我吃饱了 (I'm full / I've eaten enough).

2. can't eat anymore

► Pinyin
A. 不能再吃了 — Bù néng zài chī le
B. 不想再吃了 — Bù xiǎng zài chī le
C. 别再吃了 — Bié zài chī le
D. 没有吃 — Méiyǒu chī
► Answer
A. 不能再吃了 (Bù néng zài chī le) — 能 = can/able to. Compare the three variations: 不能再吃了 (physically can't), 不想再吃了 (don't want to), 别再吃了 (command: don't).

3. don't want to eat anymore

► Pinyin
A. 别再吃了 — Bié zài chī le
B. 不想再吃了 — Bù xiǎng zài chī le
C. 吃多了 — Chī duō le
D. 不能再吃了 — Bù néng zài chī le
► Answer
B. 不想再吃了 (Bù xiǎng zài chī le) — 想 = want/think. 不想 = don't want. Full pattern: 不想再[V]了 = don't want to [V] anymore.

4. tell him / talk to him

► Pinyin
A. 给他说 — Gěi tā shuō
B. 跟我说 — Gēn wǒ shuō
C. 跟朋友聊天 — Gēn péngyǒu liáotiān
D. 跟他说 — Gēn tā shuō
► Answer
D. 跟他说 (Gēn tā shuō) — 跟 = with, 他 = him, 说 = say/speak. The pattern 跟[person]说 = talk to/tell [person]. Note: 给他说 is not standard Mandarin; avoid it.

5. chat with friends

► Pinyin
A. 和朋友说话 — Hé péngyǒu shuōhuà
B. 跟朋友聊天 — Gēn péngyǒu liáotiān
C. 跟同学聊天 — Gēn tóngxué liáotiān
D. 跟朋友玩 — Gēn péngyǒu wán
► Answer
B. 跟朋友聊天 (Gēn péngyǒu liáotiān) — 聊天 (liáotiān) = chat/small talk. The pattern is 跟[person]聊天. Note: 和朋友说话 (talk with friends) is also correct but uses 说话 (formal talk) instead of 聊天 (casual chat).
Section 3: Fill in the Blank

Choose the word that best completes the sentence. Use 🔊 to hear the full sentence with the correct answer filled in.

1. 请你______这件事告诉他。 🔊

► Pinyin
Qǐng nǐ ______ zhè jiàn shì gàosù tā。
► Answer
B. 把 — 请你把这件事告诉他。
Qǐng nǐ bǎ zhè jiàn shì gàosù tā。
Please tell him this matter. — 把…告诉… is the 把-structure for 'tell': 把[thing]告诉[person]. The object (this matter) is moved before 告诉 by 把.

2. 我的手机跟你的______大。 🔊

► Pinyin
Wǒ de shǒujī gēn nǐ de ______ dà。
► Answer
B. 一样 — 我的手机跟你的一样大。
Wǒ de shǒujī gēn nǐ de yīyàng dà。
My phone is the same size as yours. — Pattern: A跟B一样[adj] = A is as [adj] as B. 跟 and 和 are largely interchangeable here, but 跟 is more colloquial.

3. 我的意见跟你的______。 🔊

► Pinyin
Wǒ de yìjiàn gēn nǐ de ______。
► Answer
C. 不一样 — 我的意见跟你的不一样。
Wǒ de yìjiàn gēn nǐ de bù yīyàng。
My opinion is different from yours. — Pattern: A跟B不一样 = A is different from B. Contrast with A跟B一样 (same). 差不多 (similar/about the same) is a common trap — it implies near-equality, not difference.

4. 这件衣服______那件贵。 🔊

► Pinyin
Zhè jiàn yīfú ______ nà jiàn guì。
► Answer
B. 没有 — 这件衣服没有那件贵。
Zhè jiàn yīfú méiyǒu nà jiàn guì。
This piece of clothing is not as expensive as that one. — Pattern: A没有B[adj] = A is not as [adj] as B. The negative comparison uses 没有, NOT 不比. 比 would flip the comparison: 这件比那件便宜 = this one is cheaper than that.

5. 我已经吃了很多，______。 🔊

► Pinyin
Wǒ yǐjīng chī le hěn duō，______。
► Answer
A. 原来我饱了 — 我已经吃了很多，原来我饱了。
Wǒ yǐjīng chī le hěn duō，yuánlái wǒ bǎo le。
I've already eaten a lot — turns out I'm full! — 原来 (yuánlái) = 'I see' / 'turns out' / 'so that's why' — expresses a sudden realization. It goes at the beginning of the clause revealing the discovery.
Section 4: English → Chinese Sentence Translation

Read the English sentence. Write the Chinese translation on paper or in your head, then toggle the answer. Use 🔊 next to the Chinese answer to hear it.

1. Translate: "Please give him my phone number."

► Answer
请把我的电话号码给他。 🔊
Qǐng bǎ wǒ de diànhuà hàomǎ gěi tā。
Please give him my phone number.
把 moves the object before the verb: 把[object]给[person]. Full structure: 请把我的电话号码给他. Compare: 给他我的电话号码 (same meaning, but less formal / different emphasis).

2. Translate: "Do you know the place I need to deliver to?"

► Answer
你知道我要送的地方吗？ 🔊
Nǐ zhīdào wǒ yào sòng de dìfāng ma？
Do you know the place I need to deliver to?
要+V+的+N = the [N] that [I] need to [V]. 要送的地方 = the place to deliver to. This 的 is a nominalizer linking verb to noun. Other examples: 要买的东西 (things to buy), 要做的事情 (things to do).

3. Translate: "The book I need to buy is very expensive."

► Answer
我要买的书很贵。 🔊
Wǒ yào mǎi de shū hěn guì。
The book I need to buy is very expensive.
要买的书 is a noun phrase: 我要买的 modifies 书. The whole phrase 我要买的书 acts as the subject. Word order: [modifier + 的] + noun.

4. Translate: "I have a lot of things I need to do today."

► Answer
今天我有很多要做的事情。 🔊
Jīntiān wǒ yǒu hěn duō yào zuò de shìqíng。
I have a lot of things I need to do today.
要做的事情 = things to do. 很多要做的事情 = lots of things to do. 事情 (shìqing) = matter/thing — more formal than 事 alone.

5. Translate: "The place I want to go is very far."

► Answer
我要去的地方很远。 🔊
Wǒ yào qù de dìfāng hěn yuǎn。
The place I want to go is very far.
要去的地方 = the place I'm going to go (to). The 要 here expresses intention. This pattern 要[V]的[N] naturally forms noun phrases with clear intent: 要去的地方, 要送的地方, 要买的书, etc.

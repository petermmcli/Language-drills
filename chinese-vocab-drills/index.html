Section 1: Chinese → English

1. 往右转 🔊

► Pinyin
wǎng yòu zhuǎn
► Answer
B. turn right — 往右转 (wǎng yòu zhuǎn) = turn right. 往 means "toward," so 往左转 = turn left and 往前走 = go straight.

2. 地儿 🔊

► Pinyin
dìr
► Answer
D. place / spot — 地儿 (dìr) is a colloquial Beijing word for 地方 (place). The 儿 suffix gives it the characteristic Beijing erhua sound.

3. 下单 🔊

► Pinyin
xià dān
► Answer
B. place an order — 下单 (xià dān) = to place an order (online shopping or restaurant). 下 = to submit/put down, 单 = form/receipt.

4. 往前开一点儿 🔊

► Pinyin
wǎng qián kāi yì diǎnr
► Answer
A. drive forward a little — 往前开一点儿: 往 (toward) + 前 (front) + 开 (drive) + 一点儿 (a little). Said to a driver when parallel parking or pulling up.

5. 对吧 🔊

► Pinyin
duì ba
► Answer
D. right? / isn't it? — 对吧 (duì ba) is a tag question seeking confirmation. 吧 softens it into a question. Compare: 对啊 (duì a) = "That's right!" (statement).
Section 2: English → Chinese

Read the English. Choose the correct Hanzi. Use 🔊 on each option to hear it. Toggle ► Pinyin to reveal readings.

1. so / thereupon / as a result

► Pinyin
A. 马上 — mǎ shàng
B. 于是 — yú shì
C. 到处 — dào chù
D. 不必 — bú bì
► Answer
B. 于是 (yú shì) — narrative connector meaning "so, thereupon." More formal or story-like than 所以. 马上 = right away; 到处 = everywhere; 不必 = no need to.

2. long time no see / haven't seen you in a long time

► Pinyin
A. 我想了很久 — wǒ xiǎng le hěn jiǔ
B. 很久没见 — hěn jiǔ méi jiàn
C. 很久以前 — hěn jiǔ yǐ qián
D. 很长时间 — hěn cháng shí jiān
► Answer
B. 很久没见 (hěn jiǔ méi jiàn) — "long time no see." Compare: 很久以前 = long ago; 很长时间 = a long time (duration); 我想了很久 = I thought about it for a long time.

3. no need to / unnecessary

► Pinyin
A. 对吧 — duì ba
B. 马上 — mǎ shàng
C. 不必 — bú bì
D. 于是 — yú shì
► Answer
C. 不必 (bú bì) — "no need to," more formal than 不用. Classic phrase: 不必客气 = "no need to be polite." Note: 不 becomes 2nd tone before the 4th-tone 必.

4. walk / come toward me a little

► Pinyin
A. 往右转 — wǎng yòu zhuǎn
B. 下单 — xià dān
C. 往我这儿走一点儿 — wǎng wǒ zhèr zǒu yì diǎnr
D. 往前开一点儿 — wǎng qián kāi yì diǎnr
► Answer
C. 往我这儿走一点儿 — "walk toward me a little." Same 往 (toward) + direction pattern as 往右转 (turn right) and 往前开一点儿 (drive forward a bit). 这儿 = here (erhua form of 这里).

5. everywhere / all over

► Pinyin
A. 于是 — yú shì
B. 马上 — mǎ shàng
C. 到处 — dào chù
D. 不必 — bú bì
► Answer
C. 到处 (dào chù) — "everywhere, all over." Example: 到处都是人 = "people everywhere." 于是 = so/thereupon; 马上 = right away; 不必 = no need to.
Section 3: Fill in the Blank

1. 那个______开车非常厉害。 🔊

► Pinyin
Nà ge ______ kāi chē fēi cháng lì hài。
► Answer
A. 女司机 — 那个女司机开车非常厉害。
Nà ge nǚ sī jī kāi chē fēi cháng lì hài。
That female driver is an excellent driver. — 女司机 = 女 (female/woman) + 司机 (driver). 非常 = extremely (stronger than 很). 厉害 = impressive, skilled, formidable.

2. 你可以帮我______一张照片吗？ 🔊

► Pinyin
Nǐ kě yǐ bāng wǒ ______ yí zhāng zhào piàn ma？
► Answer
B. 拍 — 你可以帮我拍一张照片吗？
Nǐ kě yǐ bāng wǒ pāi yí zhāng zhào piàn ma？
Can you take a photo for me? — 拍 = to take a photo / to film / to pat. 拍照 = take a photo (verb phrase). 帮我 = help me (do something). 一张 is the measure word for flat things like photos.

3. 请等一下，我______就过来。 🔊

► Pinyin
Qǐng děng yī xià，wǒ ______ jiù guò lái。
► Answer
C. 马上 — 请等一下，我马上就过来。
Qǐng děng yī xià，wǒ mǎ shàng jiù guò lái。
Please wait a moment, I'll be right there. — 马上 = right away, immediately. The pattern 马上就... intensifies the immediacy. 等一下 = wait a moment.

4. 你明天坐______回北京？ 🔊

► Pinyin
Nǐ míng tiān zuò ______ huí Běi jīng？
► Answer
A. 几点的飞机 — 你明天坐几点的飞机回北京？
Nǐ míng tiān zuò jǐ diǎn de fēi jī huí Běi jīng？
What time's your flight back to Beijing tomorrow? — 几点的飞机 = "what time's flight." The structure 几点的 + transport works for trains too: 几点的火车.

5. 今天走了好多路，______。 🔊

► Pinyin
Jīn tiān zǒu le hǎo duō lù，______。
► Answer
C. 我累死了 — 今天走了好多路，我累死了。
Jīn tiān zǒu le hǎo duō lù，wǒ lèi sǐ le。
I walked so much today — I'm exhausted! — V+死了 = hyperbolic intensifier ("so V I could die"). 累死了 = dead tired, 饿死了 = starving, 吓死了 = scared to death.
Section 4: English → Chinese Sentence Translation

Read the English sentence. Write the Chinese translation on paper or in your head, then toggle the answer. Use 🔊 next to the Chinese answer to hear it.

1. Translate: "A long time ago, there were no smartphones."

► Answer
很久以前，没有智能手机。 🔊
Hěn jiǔ yǐ qián，méi yǒu zhì néng shǒu jī。
A long time ago, there were no smartphones.
很久以前 always opens the sentence to set the time frame. 没有 = there is/are no... (existence negation). 智能手机 = smartphone (lit. "intelligent-ability hand-machine").

2. Translate: "The guests are arriving at seven this evening."

► Answer
今晚客人七点到。 🔊
Jīn wǎn kè rén qī diǎn dào。
The guests are arriving at seven this evening.
客人 = guest(s) or customer(s). 今晚 = this evening. Time words precede the main verb: 七点到 = "arrive at 7." Subject-time-verb is natural word order here.

3. Translate: "He has a lot of power in this company."

► Answer
他在这家公司有很大的权力。 🔊
Tā zài zhè jiā gōng sī yǒu hěn dà de quán lì。
He has a lot of power in this company.
权力 (quánlì) = power/authority. Don't confuse with 权利 (quánlì) = rights/entitlements — same pronunciation, different character: 力 (strength) vs 利 (benefit).

4. Translate: "I've been waiting for a long time."

► Answer
我等了很长时间了。 🔊
Wǒ děng le hěn cháng shí jiān le。
I've been waiting for a long time.
Duration pattern: verb + 了 + duration + 了. The trailing 了 signals the situation is still ongoing. 很长时间 = a long time (duration); 很久 = a long time (more colloquial).

5. Translate: "I thought about it for a long time before deciding."

► Answer
我想了很久才决定。 🔊
Wǒ xiǎng le hěn jiǔ cái jué dìng。
I thought about it for a long time before deciding.
我想了很久 = I thought for a long time (duration of past action). 才 = "only then / not until" — emphasizes that the decision came only after the long deliberation.
